# Mountain Home design preview

An interactive local visual reference for the native Android TV launcher. Open `index.html` or use the existing local preview. All visual assets are bundled.

Arrow keys navigate; Enter opens; Escape closes Wi-Fi; S or / explains the Google-search handoff. The home has twelve app cards in two rows, with the welcome, app heading and footer text removed. Arrow keys move vertically by six columns on the TV canvas. The old custom search dialog and service-choice UI have been removed: on TV, Search opens Google’s own interface for typing or speaking. The browser cannot launch TV apps or reproduce live Google results.

The dot explains its real TV behavior: open the original home and pause the Home helper until Mountain TV is reopened from Apps. Wi-Fi explains its TV settings shortcut. No preview action sends a TV command or makes an API request.

`home-preview.png` is a browser design capture. `tv-installed.png`, `tv-google-search.png` and `tv-google-results.png` are actual TV captures. Asset provenance is in `../assets/ASSET-CREDITS.md`.
